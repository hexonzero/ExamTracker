# Security policy

Govt Exam Tracker runs entirely in the browser. It has no server, accounts or analytics, and it stores progress only in your own browser.

## Reporting a problem

Please do not open a public issue for a security problem. Use **Security, Report a vulnerability** on this repository's GitHub page (private vulnerability reporting). Include the steps to reproduce it and the browser you used.

## What is in scope

- Ways to run script in the page, for example through a restored backup, a custom exam name or a custom topic
- Ways to bypass the Content Security Policy in `index.html`
- Data being sent to any third party
